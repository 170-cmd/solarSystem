# Оррери — интерактивная модель Солнечной системы

Обучающая демонстрация: Солнце и 8 планет движутся по орбитам с реальными
относительными периодами. Клик по планете открывает досье (название, диаметр,
расстояние от Солнца, орбитальный период, спутники, температура, факты).

## Самый простой способ — без Node.js

В проекте есть автономная версия в одном файле — `public/standalone.html`.
Она не требует npm, Node и сборки: сохраните файл и откройте его двойным
кликом в любом браузере (работает офлайн; без интернета просто подставятся
системные шрифты).

- На собранном сайте файл доступен по адресу `/standalone.html` — откройте
  его и сохраните страницу (`Ctrl+S` → «Веб-страница, только HTML»).
- Возможности те же: клик по планете открывает досье, есть пуск/пауза,
  скорости ×1–×50, сброс времени, переключатели орбит и подписей,
  клавиши `Пробел`, `←` / `→`, `Esc`.

## Быстрый старт (полная версия, React + Vite)

Понадобится **Node.js 18+** (проверка: `node -v`). Важно: запускать команды
нужно в папке, где лежат файлы проекта (`package.json` и т.д.).

```bash
# 1. зависимости
npm install

# 2. режим разработки (http://localhost:5173)
npm run dev

# 3. продакшен-сборка и предпросмотр
npm run build
npm run preview
```

## Управление

| Действие | Способ |
| --- | --- |
| Пауза / пуск | кнопка на пульте или `Пробел` |
| Скорость | ×1 / ×2 / ×5 / ×10 / ×50 (10–500 земных суток в секунду) |
| Сброс времени | кнопка ↻ на пульте |
| Выбор планеты | клик по планете / имени на орбите / точке в навигации |
| Следующая / предыдущая планета | `←` / `→` |
| Закрыть досье | `Esc` или кнопка ✕ |
| Орбиты и подписи | переключатели на пульте |

## Стек

React 18 · TypeScript · Vite 6 · Tailwind CSS v4 · SVG-анимация на rAF
(без тяжёлых 3D-библиотек — всё отрисовано вручную).

## Данные

Астрономические факты (диаметры, расстояния, периоды, температуры, спутники)
хранятся в `src/data/bodies.ts` — их легко дополнять и исправлять.
