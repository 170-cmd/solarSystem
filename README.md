# Оррери — интерактивная модель Солнечной системы

Обучающая демонстрация в двух режимах:

- **Карта (2D)** — Солнце и 8 планет движутся по орбитам с реальными
  относительными периодами; пояс астероидов, Луна, кольца Сатурна.
- **3D-полёт** — клик по планете открывает досье, и камера подлетает к ней:
  можно вращать камеру вокруг планеты, приближать и удалять, пока планета
  продолжает лететь по орбите. Процедурные текстуры, осевые наклоны
  (Уран «лежит на боку»), кольца Сатурна со щелью Кассини, облака Земли.

Клик по любому телу открывает досье: название, диаметр, расстояние от Солнца,
орбитальный период, длина суток, спутники, температура и факты — со
сравнительными шкалами относительно Земли.

## Как скачать проект

Прямо в шапке приложения есть кнопка **«Проект ZIP»** — она упаковывает все
исходники в архив `solar-system.zip` одним кликом.

## Быстрый старт

Понадобится **Node.js 18+** (проверка: `node -v`). Запускать команды нужно
в корне проекта, где лежит настоящий `package.json`.

```bash
# 1. зависимости
npm install

# 2. режим разработки (http://localhost:5173)
npm run dev

# 3. продакшен-сборка и предпросмотр
npm run build
npm run preview
```

## Управление

| Действие | Способ |
| --- | --- |
| Пауза / пуск | кнопка на пульте или `Пробел` |
| Скорость | ×1 / ×2 / ×5 / ×10 / ×50 (10–500 земных суток в секунду) |
| Сброс времени | кнопка ↻ на пульте |
| Досье планеты | клик по планете (в 2D и в 3D), стрелки `←` / `→`, точки в навигации |
| Подлёт камеры к планете | клик по планете **в 3D-режиме** (в 2D открывается только досье) |
| Следующая / предыдущая планета | `←` / `→` или кнопки в досье |
| Камера в 3D | ЛКМ — вращение, колесо — масштаб, ПКМ — перемещение |
| Вернуться к карте | кнопка «К карте», режим «Карта» на пульте или `Esc` (дважды) |
| Орбиты и подписи | переключатели на пульте |

## Стек

React 18 · TypeScript · Vite 6 · Tailwind CSS v4 · Three.js (react-three-fiber
и drei) для 3D-режима · SVG + rAF для 2D-карты. Текстуры планет рисуются
процедурно на canvas — внешних изображений нет.

## Данные

Астрономические факты (диаметры, расстояния, периоды, температуры, спутники)
хранятся в `src/data/bodies.ts` — их легко дополнять и исправлять.
